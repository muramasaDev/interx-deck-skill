# ixdeck:sheet: xlsx 정의서

엔진 `${CLAUDE_PLUGIN_ROOT}/scripts/ixsheet.py`, 출발 파일 `scripts/example_sheet.py`, 검사 `scripts/sheet_check.py`, 그림 `scripts/xlsx_view.py`. PPT 가 아니라 목록형 xlsx 용이며 회사 PPT 양식과 별개로 일관성 및 정렬만으로 완성도를 낸다.

## 서식 규칙
- 표 하나는 시트 하나. 시트 이름은 표 이름 (31자 이내, 금지 문자는 `_`)
- 1행 표 제목(왼쪽, 굵게) 및 오른쪽 끝 `(단위: ...)`, 2행 머리행(필터), 3행부터 데이터, 틀 고정은 머리행 아래. 머리행 위 그룹 머리 한 줄만 병합 허용 (그러면 머리행은 3행)
- 데이터 영역은 병합 금지, 빈 셀 금지(없으면 `-`), 한 셀 한 값, 300자 초과는 경고 (여러 값은 하위 표 시트로 나눔)
- 열 종류 `Field(이름, 종류)`

| 종류 | 정렬 및 서식 |
|---|---|
| id | 가운데. 첫 열이면 중복 ID 를 ValueError 로 막음 |
| code | 가운데 (Method, 구분 등) |
| text | 왼쪽, 자동 줄 바꿈, 세로 위쪽 |
| num | 오른쪽, `#,##0` 또는 `decimals=` 자리수, `unit=` 은 머리에 `(단위)` |
| date | `YYYY-MM-DD` 가운데 (잘못된 날짜는 ValueError) |
| status | 가운데 + 옅은 채움 (완료 초록, 진행 노랑, 계획 회색, 미정 연한 빨강, `mapping=` 로 바꿈) |

- 글꼴 `맑은 고딕` 하나. 데이터 및 머리 10pt, 머리는 굵은 흰 글자에 남색(002060) 채움, 제목 12pt 굵게. 격자 가는 선(BFBFBF), 줄무늬 없음, 강조는 상태 칸만
- 행 높이는 글자 수와 열 너비로 계산해 숫자로 지정 (한 줄 18pt, 줄 수 x 15 + 3). 열 너비는 지정하거나 내용 길이로 자동 (8 이상 60 이하)
- 인쇄 A4 가로, 너비 1쪽 맞춤, 머리행 반복, 바닥글 문서명 왼쪽, 쪽 번호 가운데, 시트 이름 오른쪽
- 모든 책 맨 앞에 `문서 정보`(항목 및 내용), 둘째 `개정 이력`(판, 일자, 구분, 내용). 작성자 열은 두지 않음
- `matrix(이름, 행 ID 목록, 열 ID 목록, 연결 쌍, corner=)` 은 연결을 `●`, 없으면 `-` 로 표시
- `table(이름, 열 목록, 행, unit=, group={라벨: (시작 열 이름, 끝 열 이름)})`: unit 은 표 오른쪽 위 `(단위: ...)`, group 은 머리행 위의 병합 그룹 줄 (머리 줄에서만 병합 허용). `Field(이름, 종류, width=, decimals=, unit=, mapping={상태 값: 채움 색})`
- 행이 사전이면 키가 열 이름과 정확히 같아야 함 (빠지거나 여분이면 ValueError). 이름, 머리, 단위, 그룹 라벨은 비거나 `=` 로 시작하면 거부. 날짜는 1900-03-01 이후, 한 행 높이는 409pt 이하
- 그림 확인 `xlsx_view.py` 는 Playwright (`pip install playwright`) 와 Edge 또는 Chrome 이 있어야 함

## 쓰는 순서
1. `scripts/example_sheet.py` 를 작업 폴더에 `build_sheet.py` 로 복사하고 `sys.path.insert` 경로를 엔진 `scripts` 폴더로 바꾼다
2. `Book(title, info, history)` 의 문서 정보, 개정 이력, 표별 `Field` 및 행 데이터를 교체한다 (행은 열 순서의 목록 또는 열 이름 키의 사전)
3. `python -P build_sheet.py 출력.xlsx`. 저장 때 규칙 오류는 ValueError 로 멈추고 경고는 출력
4. `python -P scripts/sheet_check.py 출력.xlsx` 가 "결과: 통과" 여야 함 (오류 시 종료 코드 1)
5. `python -P scripts/xlsx_view.py 출력.xlsx 그림폴더 --rows 40` 으로 시트별 PNG 를 만들고 바뀐 시트는 눈으로 본다 (잘림, 정렬, 줄 수). 실제 Excel 과 똑같지는 않은 근사
6. 엔진 자체 시험은 `python -P scripts/selfcheck_sheet.py` (`selfcheck_sheet OK`)

## 검사가 잡는 것
- 오류: 데이터 영역 병합, 빈 셀, 중복 ID(첫 열 머리가 ID 또는 번호로 끝날 때), 머리행 이름 중복, 숫자가 글로 저장됨, 날짜 서식, 틀 고정 또는 필터 없음, 글꼴, 행 높이 미지정, 첫 두 시트 이름
- 경고: 300자 초과 셀, 열 너비 또는 행 높이가 모자라 잘림, 시트 이름 길이

## 하지 말 것
- Excel 이나 PowerPoint COM 으로 xlsx 를 열거나 PDF 로 내보내기 (DRM 으로 암호화됨). 읽기와 쓰기는 openpyxl 만, 그림은 xlsx_view 로
- 데이터 영역 병합, 빈 셀, 한 셀에 여러 값이나 300자 넘는 긴 글
- 줄무늬, 색 강조 남발, 글꼴 혼용. 상태 칸 외에는 색을 쓰지 않음
- 실제 납품 파일을 직접 고치지 않고 사본으로 작업
- 글쓰기: 가운뎃점, 긴 줄표 금지, 명사 나열은 `및`, 개조식, 추측과 기대 효과 서술 금지
