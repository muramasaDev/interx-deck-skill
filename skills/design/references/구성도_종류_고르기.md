# 구성도 종류 고르기

- 용도: 사용자가 구성도를 요청했는데 종류를 정하지 않았을 때 묻는 객관식과, 종류별 엔진 부품
- 예제: `scripts/example_architecture.py` (네 종류 한 벌), `scripts/example_diagram.py` (배치도, 대응표, 순서)
- 묻는 방법: AskUserQuestion 한 번에 "구성도 종류"(여러 개 선택 가능)와 "번호 표기"를 묻고, 답에 맞는 예제를 build.py 로 복사해 내용만 바꿈

## 1. 객관식 (복사해서 쓸 질문)
| 선택지 | 답하는 질문 | 맞는 경우 | 엔진 부품 |
|---|---|---|---|
| 계층형 가로 띠 | 어떤 계층(단말, 서버, 제어기, 현장 장치)이 어떻게 쌓여 있나 | 제어와 모니터링, 현장 장치부터 단말까지 계층이 분명한 시스템 | `layer_bands`, `bus_line`, `role_box`, `link` |
| 구역 배치도 | 어떤 구역(DMZ, 내부망, 서브넷)에 무엇이 놓이고 어디까지 열려 있나 | 클라우드, 서버실, 보안 구역 구분, 3계층(웹, WAS, DB) | `zone_box`, `server`, `db`, `tier_spec`, `node`, `link` |
| 토폴로지 | 무엇이 무엇과 어떤 프로토콜로 이어지나 | 네트워크, 장비 연결, 외부 시스템 연계 | `node`, `link` (선 위 `text=` 로 프로토콜) |
| 등각 | 구역과 서버를 입체 느낌으로 한눈에 | 소개용 그림. 편집 가능한 도형이라 정밀한 3D 가 아니고 선은 꺾은선. PowerPoint 에서 육면체를 옮기면 연결선이 윗면으로 다시 붙을 수 있음 | `iso_plate`, `iso_box`, `link` |
| 기능별 배치도 | 기능 묶음이 어디에 들어 있고 값이 어디서 어디로 가나 | 제품이 EdgePC 와 서버에 걸쳐 기능을 나눔 | `DocGrid`, `group`, `sub`, `tone=`, `flow=` |
- 기본 추천: 시스템 층이 분명하면 계층형, 보안이나 네트워크 경계가 핵심이면 구역 배치도, 기능 소유가 핵심이면 기능별 배치도
- 한 장에 한 질문: 종류를 섞지 않고 장을 나눔

## 2. 번호 표기 (선택지)
| 선택지 | 방식 | 맞는 경우 |
|---|---|---|
| 선 위 번호와 옆 짧은 글 (기본) | 번호 원이 선 위에 얹히고 짧은 글이 바로 붙음 (`link(step=(번호, 글))`) | 선이 길고(1 in 안팎 이상) 글이 8자 안팎 |
| 번호만 선 위, 설명은 다음 장 표 | 그림은 번호만, 다음 장에 번호, 처리, 출발, 도착, 값 표 | 선이 짧고 설명이 긴 경우 |
- 번호가 어느 선의 것인지 모호하면 안 됨: 엔진이 번호를 선 위에 얹고, 선 위에 못 얹으면 주의를 냄 (그때는 번호 대신 선 이름 `text=`)

## 3. 이름 규칙 (처음 보는 사람 기준)
- 상자 이름은 대상과 동작: `수집 항목 및 주기 제공` (○), `수집 계획 제공` (×, 무슨 계획인지 모름)
- 계획, 정보, 데이터, 자료, 값, 내용, 설정, 기능, 서비스, 모듈 뒤에 제공, 전달, 처리 같은 동사만 붙인 이름은 저장 때 주의
- 줄일 수 없으면 구성도 아래 `abbr_legend(s, x, y, w, abbrs=[("수집 계획", "수집 항목과 주기를 적은 설정")])` 로 첫 용어를 한 줄 풀이 (풀이한 용어는 주의에서 빠짐)
- 원천 명칭 그대로 쓰고 내가 만든 용어는 만들지 않음

- 띠와 구역(`layer_bands`, `zone_box`)은 상자와 선보다 먼저 부름 (나중에 부르면 저장 때 오류)

## 4. 계층 구분 점검 (구성도 공통)
1. 계층 이름이 띠 오른쪽에 있고 띠마다 같은 높이인가 (`layer_bands`)
2. 계층을 가로지르는 공통 통신선은 `bus_line` 으로 이름을 붙였나
3. 상자가 자기 계층 띠 안에만 있고 띠를 걸치지 않았나
4. 계층 사이 선에 프로토콜이나 값 이름이 있나
5. 구역(DMZ, 내부망)은 `zone_box` 이름표와 색 종류(public, private, dmz, cloud)가 뜻과 맞나
