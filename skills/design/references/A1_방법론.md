# INTERX 제조 AI 및 데이터 분석 방법론 요약 (A1. 전략 수립 절차서, 공정 분야)

- 원본: INTERX 제조AI 및 데이터 분석 방법론 A1. 전략 수립 절차서 공정분야 V3.0 (2023.02), 사내 자료
- 용도: 설계 문서, 제안 덱, 수행계획서의 장 구성과 용어를 회사 방법론에 맞춤
- 이 요약은 글만 옮김. 원본 그림은 넣지 않음. 수치는 원본 예시 값

## 1. 전략 수립 절차 (7단계)

| 단계 | 할 일 | 엔진 부품 |
|---|---|---|
| 1. 전략 수립 개요 | 제조 혁신 전략 검토, 제조 AI 활용 이해 | `chevrons` |
| 2. 추진 체계 구성 | 5개 역할 구성 (아래 2절) | `DocGrid` 또는 `num_cards` |
| 3. 과제 도출 | 현업 문제 및 개선점 파악, 수준 진단, 유사 사례, 도입 효과 및 실행 가능성, 우선순위, 로드맵 | `Col.levels`, `Col.priority_table`, `Col.priority_quad`, `gantt` |
| 4. 데이터 수집 방안 검토 | 필요 데이터 정의 (표준 데이터셋), 수집 가능성, 수집 개선, 품질 관리, 보안 | `Col.das_table`, `Col.quality_table`, `DocGrid` |
| 5. 분석 방안 수립 | 공정 특성 및 상관관계 분석, 알고리즘 검토, 모델 생성 및 시험 방안 | `Col.table`, `Col.chart` |
| 6. 활용 계획 수립 | 시각화, 현업 적용, 확대 적용, 도입 효과 측정 (6 ~ 12개월), 모델 유지보수 및 업그레이드 | `chevrons`, `Col.kpi_table` |
| 7. 프로젝트 추진 계획 | 분석 목표 명세서, 성과지표, 데이터 수집 및 전처리 계획, 기초 통계 및 분석 계획, 모델 개발 및 시험 계획, 시각화 및 서비스, 비용 및 기간 | `kpi_table`, `gantt`, `d.deliverables` |

- 설계 문서 장 순서: 4단계(수집 방안) → 5단계(분석 방안) → 6단계(활용 계획) → 7단계(추진 계획)
- 과제 도출 순서: 현업 과제 접수 및 혁신 전략 검토 → 경영자 및 현업 인터뷰, 유사 사례 벤치마킹 → 수집 및 분석 가능성 검토, 과제 타당성 평가 (시급성, 중요도, 데이터 유무, 비용) → 추진 과제 선정

## 2. 추진 체계 (5개 역할)

| 역할 | 약칭 | 하는 일 | 소속 |
|---|---|---|---|
| 의사결정권자 | 전략 | 혁신 전략과 방향, 추진 의사결정 | 기업 내부 |
| 현장 및 공정 전문가 | OT | 현업 문제점, 현장 경험 지식 | 기업 내부 |
| IT 부서 전문가 | IT | 수집 및 분석 시스템 구현 방안 | 기업 내부 |
| AI 및 데이터 전문가 | AI | 수집, 분석, 서비스 경험과 사례 | 기업 외부 |
| 데이터 표준 및 통신 전문가 | 표준 | 수집, 저장, 운영, 유통의 글로벌 표준 | 기업 외부 |

## 3. 과제 도출 고려사항

| 기준 | 확인할 것 |
|---|---|
| 도입 목적 | 기대효과 명확화 (PQCD 향상, 최적화, 예측, 손실비용 절감), 제조 혁신 전략과 연관 |
| 데이터 수집 가능성 | 필요 데이터 수집 여부, 품질, 추가 수집이 기간 안에 가능한지 |

| 분석 가능성 | 분석 가능 여부, 제약사항 해결 |
| 예산 비용 | 투자효과, 예산 확보 |

## 4. 수준 단계 (Level)

| 단계 | 구분 | 분석 | 질문 |
|---|---|---|---|
| Level 1 ~ 2 | 기초: 점검, 모니터링 | 현상 분석 | 어떤 데이터를 어떻게 수집, 무엇을 모니터링 |
| Level 3 | 중간1: 분석, 제어 | 원인 분석 | 어떤 현상을 분석, 원인 분석 정합성 |
| Level 4 | 중간2: 최적화 | 예측 분석 | 학습모델과 예측모델 정합성 |
| Level 5 | 고도화: 자율운영 | 예방 분석 | 예방모델 정합성 |

- 분야 6개: 생산관리, 품질관리, 물류 및 재고관리, 설비관리, 안전 및 환경관리 (LCA 대응), 에너지관리
- 과제 이름 꼴: Level 3 '~ Zero화 (문제분석/인지)', '~ 신속 대응 및 개선', '~ 최소화'. Level 4 '~ 예측 및 사전예방', '~ 예측 및 제어'. Level 5 '~ 자율화', '~ 최적화 자율운영'
- 자율 공장 목표 (회사 목표 수치, 근거 자료 없음): 예측 기반 3시간 이상 무인 자율 운영, 생산성 200% 향상, 불량률 50% 감소, 비용 50% 절감, 납기 50% 단축. 인용하면 '회사 목표 수치' 로 밝힘

## 5. 과제 우선순위

| 축 (50%) | 기준 | 가중치 | 질문 |
|---|---|---|---|
| 전략적 중요도 | 성과향상 기여도 | 40% | 성과향상에 얼마나 기여 |
| | 효과의 크기 | 30% | 파급효과 크기 |
| | 시급성 | 30% | 얼마나 시급 |
| 실행의 용이성 | 투자 용이성 | 40% | 투자 의사결정이 쉬운지 |
| | 효과발생 용이성 | 40% | 효과가 쉽게 가시화되는지 |
| | 관리 용이성 | 20% | 실행 관리가 쉬운지 |

- 점수 1 ~ 5, 축 점수는 가중합, 총점은 두 축의 합
- 4분면: Quick Win (QW, 단기실행, 중요도 높고 쉬움), Strategic Initiatives (SI, 중장기, 중요도 높고 어려움), Nice to Have (NH, 선택), Leave for Now (LN, 배제)

## 6. 데이터 수집 방안

- 고려사항: 분석용 표준 데이터셋 정의 (현업, IT, 분석 전문가 협의, Xn 및 Yn 특성 고려), 수집 가능성, 데이터 정확성 (품질 기준과 대응), 수집 비용, 데이터 보안
- 절차: 해결 과제의 수집 데이터 특징 이해 → 분석용 표준 데이터셋 정의 (Xn, Yn 구조) → 수집 방법 및 기술 검토 (정확성, 비용, 보안)

### 변수 구조 Yn = f(Xn)

| 구분 | 이름 | 내용 |
|---|---|---|
| X1 | 작업변수 (Working Data) | 생산지시 (Order), 투입 소재 특성 (Material), 설비 상태 (Machine Situation), 작업자 (Worker) |
| X2 | 환경변수 (Environment Data) | 공정 주변 온도, 습도, 진동 |
| X3 | 셋팅변수 (Setting Data) | 설비 셋팅 데이터 |
| X4 | 실행변수1 (Dynamic Actual Data) | 동적 동작 데이터 |
| X5 | 실행변수2 (Shot Actual Data) | 정적 동작 데이터 |
| Yn | 결과(목적)변수 (Output Data) | 품질결과, 생산결과, 물성치 |

- Yn 목적 예: Y1 생산 최적화, Y2 품질 최적화, Y3 설비 최적화, Y4 물류 최적화, Y5 안전 최적화, Y6 공급망 최적화

### 데이터 수집 명세서 (DAS, Data Acquisition Specification)
- 머리: Company, Factory, Line, Process, Process Type, Analysis Type (Edge Tier 또는 Enterprise Tier), Analysis Usage (Descriptive, Diagnostic, Predictive, Prescriptive), Data Quality 항목
- 칸: Data, Expression, Data Type, Range, Acq. Time, Unit, Stage, Connected, Data Quality, Comment
- 구조 정의: AAS (Administration Shell, Asset), FBS (Functional Breakdown Structure, Level 0 Main Module ~ Level 3 Data), AAS, XML, JSON 기반

### 데이터 품질 지수
- 제조 데이터 품질 95% 이상 필수
- 품질 지수 = 완전성 (누락) x 60% + 유일성 (중복) x 10% + 유효성 (유효) x 10% + 일관성 (표현) x 10% + 정확성 (실제) x 10%
- 원본 예시: 완전성 97.38%, 나머지 100% → 품질 지수 98.43%, 오류율 1.57%

## 7. 분석 및 활용

- 분석 절차: 공정 특성 분석 → 문제 원인 데이터 상관관계 분석 → 분석 및 학습 알고리즘 검토 → 모델 생성 및 관리 → 시험 및 검증
- 분류 성능 평가: 혼동행렬, 재현율 TP/(TP+FN), 정밀도 TP/(TP+FP), 특이도 TN/(TN+FP), F1. 원본 예시는 분류 정확도 (SVM 66 ~ 73%, RandomForest 90.33%, XGBoost 90.54%, LightGBM 90.8%)
- 활용: 시각화 및 현업 적용 → 도입 효과 분석 (적정 기간 6 ~ 12개월, 정량화) → 모델 성능 관리, 유지보수 및 업그레이드 (분석 log, Relearning)
