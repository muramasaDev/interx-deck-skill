# AI 학습데이터 명세서 작성 순서

- 출처: M.AX 얼라이언스 추진단 작성 가이드(2026.11.17), 양식 HTML 2.0 (작성용과 취합용)
- 용도: 어떤 단계에 무엇을 쓰는지, 값이 어디서 이어지는지, 제출 전에 흔히 틀리는 곳
- 도구: `scripts/ixspec.py` (채우기 및 점검), `scripts/spec_verify.py` (브라우저 저장본 비교), 출발점 `scripts/example_spec.py`

## 1. 파일 두 가지
| 파일 | 쓰는 사람 | 용도 |
|---|---|---|
| 기관별작성양식.html (작성용) | 참여기관, 주관기관 | 기관이 맡은 AI 모델의 명세서 작성 |
| 취합및제출양식.html (취합용) | 주관기관 | 작성용 파일들을 불러와 하나로 취합하고 내보냄. 최종 제출은 취합 HTML |
- 같은 기관과 같은 모델명을 다시 불러오면 새 내용으로 교체됨. 기제출 과제는 갱신해서 다시 작성

## 2. 작성 7단계와 값의 연결
| 단계 | 쓰는 것 | 연결 ID |
|---|---|---|
| (1) 문제 정의 | 모델명, 대상 기업과 소재 지역, 문제 개요, 대표 이미지, 대상 업종 및 공정(최대 5), 기대 효과 | T# |
| (2) 공정, 설비, 수집 장치 | 상세 공정(대상 공정 T# 선택), 설비(해당 시), 수집 장치(공정 P# 과 설비 E# 선택, 종류별 특성) | P#, E#, S# |
| (3) 원시 데이터 | 데이터별 기본 정보(유형, 이름, 기간, 출처, 건수, 용량 MB), 수집 장치 S# 체크, 유형별 상세, 변수 목록(사용: 모델 입력, 예측 대상, 미사용), 라벨, 원시 데이터 예시 | D# |
| (4) 전처리 데이터 | 처리 단계(대상 D#, 순서가 처리 순서), 학습 사용 구간, 전처리 후 건수와 용량 | R# |
| (5) AI 준비 데이터 | 모델 입력 및 출력(자동 채움 가능), 데이터 간 맥락 연결 기준, 학습, 검증, 테스트 비율 | D# |
| (6) AI 모델 | 알고리즘, 학습 방식(AI Task), 성능 지표와 목표값, 학습 조건, 개발 환경 | |
| (7) 기타 | 과제 이슈, 특이 사항 (선택) | |
- 연결 흐름: 대상 공정 T# > 상세 공정 P# > 설비 E# > 수집 장치 S# > 원시 데이터 D# > 전처리 > AI 모델
- 앞 단계가 비면 뒤 단계 선택지가 비므로 위에서 아래로 채움 (빌더는 ID 를 순서대로 돌려줌)

## 3. 칸 쓰는 규칙 (가이드 표에서)
- 건수: 숫자만(정수), 쉼표와 단위 금지. 용량: MB 로 환산한 숫자만
- 수집 기간 예 `2024.04 ~ 2025.03`, 저장 형식 예 csv, png, mp4
- 업종 목록에 없으면 직접 입력(빌더는 `custom` 으로 저장하고 주의를 냄). 세부 구분이 없는 업종은 비움
- 수집 장치는 종류를 고르면 종류별 특성 칸이 생김 (센서: 측정 범위 등, 카메라: 해상도 등). 작성할 수 있는 것만 씀
- MES 처럼 설비에 설치되지 않은 장치는 설치 설비를 비움 (`equip=""`)
- 변수 목록의 사용 칸이 모델 입력 및 출력에 반영됨. 라벨은 이미지, 영상, 3D 에서 있음 또는 없음
- 원시 데이터 예시: 시계열과 테이블형은 머리글 포함 3~5행, 이미지는 대표 이미지(라벨 유형별 1장 이상), 영상은 대표 장면 2~3장, 텍스트는 원문 일부
- 전처리 후 결과는 전처리 단계가 있는 데이터만. 전처리가 없으면 쓰지 않음
- 학습 방식(AI Task)은 데이터 유형별 목록에서 고름. 목록에 없으면 기타와 직접 입력

## 4. 양식이 검사하지 않는 것 (직접 막아야 함)
- 양식은 저장과 내보내기에서 필수 항목을 검사하지 않음. 별표는 표시일 뿐
- 불러올 때 없는 D#, S# 참조와 쉼표 든 숫자, 허용 밖 이미지는 조용히 지워짐: `spec_verify.py` 가 이를 잡음
- 제출 검증 규칙은 양식에 없음: 별표 항목과 추가 단추 조건을 기준으로 `ixspec.check_state` 가 15가지를 점검

## 5. 제출 전 점검표
1. 모든 모델의 필수 항목(별표)이 차 있는가 (빌더 오류 0건)
2. `spec_verify.py` 가 통과(값이 빠지지 않음, 화면 오류 없음)인가
3. 모르는 값을 지어내지 않았는가 (확인 필요 목록에 남겼는가)
4. 자유 글에 가운뎃점과 긴 줄표가 없는가 (선택 목록 값은 원문 그대로)
5. 파일 이름이 양식 규칙인가 (작성: `AI학습데이터명세서_작성_기관_과제번호.html`, 취합: `AI학습데이터명세서_취합_과제번호_주관기관.html`)
6. 제공동의서는 별도 서식이므로 메일에 첨부된 서식을 따로 확인
