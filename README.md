# ixdeck

INTERX 업무 및 기안에 필요한 PPT 제작 Claude Code 플러그인 입니다.

## Install

**Windows** (PowerShell)
```powershell
npx --allow-git=all muramasaDev/interx-deck-skill
```

**macOS** (터미널)
```sh
npx --allow-git=all muramasaDev/interx-deck-skill
```

- Node.js 18 이상, 이 저장소 읽기 권한(GitHub 로그인) 필요
- Python, 패키지, 글꼴은 설치 중 자동 설치
- 설치 뒤 Claude Code 다시 시작
- 업데이트: 같은 명령 (새 판이 나오면 Claude Code 시작 때 알림)
- 점검: 명령 끝에 `doctor` / 제거: 명령 끝에 `uninstall` / 특정 판: 명령 끝에 `#v1.7.4`

## Use

Claude Code 에서 말로 요청

| 명령 | 용도 | 요청 예 |
|---|---|---|
| `/ixdeck:report` | 보고 자료, 고객 보고, 주간보고 | "○○ 결과 보고 덱 만들어 줘" |
| `/ixdeck:design` | 설계 문서, 구성도 | "수집 흐름 구성도 그려 줘" |
| `/ixdeck:okr` | 월간 Individual OKR | "이번 달 OKR 써 줘" (지난달 덱 함께 전달) |
| `/ixdeck:sheet` | xlsx 정의서 (테이블, API, 기능 항목, 화면, 추적 매트릭스) | "API 정의서 xlsx 로 만들어 줘" |
| `/ixdeck:using` | 어느 명령을 쓸지 모를 때 | |

- 덱마다 작성자, 파일 이름, 판 번호를 먼저 확인
- 결과: 작업 폴더에 pptx (`제목_작성자_v버전_YYMMDD`). PDF 는 만들지 않으며 필요하면 직접 저장
- 수정: "3장 표를 아래로" 처럼 말로 요청하거나 PowerPoint 에서 직접 수정

## What it does

- 회사 양식 배치: 표지, 목차, 본문, Thank you 및 패널, 카드, 표, 차트, 일정, 구성도, 수식을 자동 배치
- 편집 가능한 결과물: 모든 상자, 선, 표, 차트를 PowerPoint 에서 바로 수정
- 관문 검사: 겹침, 넘침, 글꼴, 제목 규칙, 금지 표현, AI 투 문장을 저장 전에 검사
- 사람이 쓴 덱 검토: 검토 에이전트가 장마다 결론, 숫자, 용어, 시제를 대조해 고칠 곳을 찾고 다시 검토
- 렌더 확인: 장마다 그림으로 확인 (PDF 는 만들지 않음)
- OKR: 지난달 덱, git 기록, Jira, 캘린더에서 실적 근거를 모아 당월 실적 및 익월 계획 작성
- xlsx 정의서: 한 표 한 시트, 머리행 필터 및 틀 고정, 병합 및 빈 셀 금지, 정렬 규칙, A4 인쇄 설정을 지켜 만들고 검사 및 그림 확인

## Notice

- 1.7.4 부터 관문이 PDF 를 자동으로 만들지 않음: 필요하면 PowerPoint 에서 직접 저장
- 1.7.2 부터 이름이 `interx-deck` 에서 `ixdeck` 으로 바뀜: 설치 명령은 같고 호출은 `/ixdeck:using` 등. 옛 설치 경로 `skills/interx-deck` 는 새 폴더로 연결해 두며 덱 빌더는 고치지 않아도 동작
- 회사 DRM: PowerPoint 로 한 번 연 파일은 Claude 가 다시 읽지 못함. 받을 사람에게는 사용자가 직접 PDF 로 저장해 전달
- macOS 에서 PowerPoint 가 없으면 LibreOffice 로 렌더 (줄 바꿈이 조금 다를 수 있음)
- 고객사 이름, 설비 이름, 회사 데이터는 공개 범위가 정해지기 전에 외부 서비스로 보내지 않음
- INTERX 사내 전용. 함께 배포하는 글꼴 Noto Sans KR 은 SIL OFL 1.1
- AI 티 판정 규칙: im-not-ai (MIT)
